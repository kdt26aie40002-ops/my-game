# Bouncy Buddies（バウンシー・バディーズ）

ブラウザで遊べる3D物理アクションゲームです。ころころしたキャラクターを操作して、空に浮かぶアスレチックコースのゴールを目指します。1人プレイと、同じキーボードでの2人協力プレイに対応しています。

**遊ぶ：** https://kdt26aie40002-ops.github.io/my-game/

## 操作方法

| 操作 | 1P | 2P |
|---|---|---|
| 移動 | W A S D | 矢印キー |
| ジャンプ（長押しで高く） | スペース | Enter |
| ダイブ（飛びこみ） | 左Shift | 右Shift |
| チェックポイントへ戻る | R | BackSpace |
| ポーズ | Esc | Esc |

- 1人プレイでは矢印キーと Enter でも操作できます。
- キー割り当ては「設定」画面から変更できます。
- ゲームパッドは1台目が1P、2台目が2Pです。
- ジャンプ中にすぐダイブすると、ふつうのジャンプでは届かない大きな穴を越えられます。

## 自分のPCで動かす

必要なもの：[Node.js](https://nodejs.org/)（LTS版）

```
npm install
npm run dev
```

ブラウザが自動で開きます。開かない場合は http://localhost:5173 を開いてください。

公開用のファイルを作る場合は `npm run build` を実行します。`dist` フォルダに出力されます。

## 公開（GitHub Pages）

`main` ブランチに push すると、GitHub Actions（`.github/workflows/deploy.yml`）が自動でビルドして公開します。

初回だけ、リポジトリの **Settings → Pages → Source** を **GitHub Actions** にしてください。

## 改造のヒント

- 操作感（速さ・ジャンプ力・重力など）：`src/config.js`
- ステージ：`src/stages/stage1.js` などを参考に新しいファイルを作り、`src/stages/index.js` に追加します。
- キャラクターの見た目：`src/character.js`
- 配色：`src/config.js` の `PLAYER_STYLES`

## 使っている技術

Three.js（3D描画）、Rapier 3D（物理演算）、Vite（ビルド）。効果音とBGMは Web Audio API でその場で合成しているので、音声ファイルは使っていません。
